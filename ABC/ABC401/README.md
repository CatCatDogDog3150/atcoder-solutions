# ABC401 A - Arrange

## 問題概要
整数Sが与えられ、それが200以上299以下の範囲にあれば"Success"、そうでなければ"Failure"を出力する問題です。

## 提出結果
- 実行時間: 33 ms
- メモリ: 14260 KB
- 結果: AC（Accepted）

## 解法
単純な条件分岐問題です。
1. 入力として整数Sを受け取る
2. if文でSが200以上かつ299以下かをチェック
3. 条件に当てはまれば"Success"、そうでなければ"Failure"を出力

## メモ
- 制約条件：100 ≤ S ≤ 999
- 非常に基本的な問題だが、プログラミングの基礎となる条件分岐をしっかりと確認
